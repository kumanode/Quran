# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-29

### Features

- **Ad-free Experience**: Full Quran reading experience without advertisements
- **30+ Translations**: Access to over 30 translations in multiple languages including:
  - Arabic (Tafsir Al-Tabari, Tafsir Al-Qurtubi, etc.)
  - English (Pickthall, Yusuf Ali, Sahih International, etc.)
  - Indonesian (Muntakhab Khoe)
  - Malay (Penggalang Bahasa)
  - Urdu (Fateh Muhammad Jalandhari)
  - Persian, Turkish, French, German, Russian, and more
- **15+ Recitations**: Multiple Qira'at (recitations) with different canonical readings
  - Mishary Rashid Alafasy
  - Sultan Al-Ajmi
  - Mohamed Al-Luhaidan
  - Ahmed Ibn Ali Al-Ajmi
  - Ibrahim Al-Dossari
  - And more...
- **Tafsir Integration**: Comprehensive tafsir (exegesis) commentary from renowned scholars
- **Multiple Fonts**: Choice of Quran fonts for optimal readability
  - Uthmanic Script fonts
  - Clear line-breaking fonts
- **Advanced Search**: Quick search across text translations and Arabic text
- **Bookmarking System**: Save your reading position and important verses
- **Reading History**: Track your recent reading sessions
- **Deep Linking**: Direct links to specific verses using quran.com URLs
- **App Widgets**: Home screen widgets for quick access to recent verses
- **Background Playback**: Continue listening with screen off using foreground services
- **Multi-language Interface**: Interface available in 15+ languages
  - Arabic, English, Indonesian, Malay, Urdu, Persian, Turkish, French, German, Russian, Bengali, Gujarati, Hindi, Kyrgyz, Spanish, Italian, and more

### Technical Improvements

- **Modern Android Architecture**: Built with Jetpack Compose and Material 3 design
- **Room Database**: Local caching with Room and KSP for fast access
- **Media3 (ExoPlayer)**: Advanced audio playback with Media3
- **Navigation Component**: Screen navigation with safe type-safe arguments
- **Paging 3**: Efficient list rendering for large datasets
- **DataStore**: Modern SharedPreferences replacement for user preferences
- **WorkManager**: Background tasks for database synchronization
- **ProGuard Enabled**: Optimized and obfuscated release builds
- **Material 3 Design**: Modern, responsive UI with dynamic colors
- **Accessibility**: Improved accessibility support for visually impaired users

### Bug Fixes

- Fixed verse navigation issues
- Improved search result accuracy
- Resolved offline caching problems
- Fixed translation text alignment issues

### Improvements

- Optimized database loading time
- Reduced app size with resource shrinking
- Improved image loading performance
- Enhanced search indexing speed
